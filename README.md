Alpha 0.26 adds bounded stack and AST introspection, native-first quarantined neural proposals, descriptive arithmetic confidence scoring, and explicit regression-gated activation of predefined strategies with rollback. No arbitrary method rewriting or neural fact ingestion. The default strategy remains exact-v1. A synthetic 103-case whitespace-focused experiment improved correct outcomes from 70 to 103 with zero regressions; a deliberately faulty candidate scored 5 and was rejected. This is a targeted regression experiment, not a general intelligence benchmark. **137/137 V6 and 70/70 inherited V5 test executions passed locally.**

## Limitations

Live local model validation, broad dependency-aware revision, recursive adaptation beyond the bounded appraisal, general experiments, representative confidence calibration, external evidence retrieval, independent scientific validation and external security certification remain outstanding. Model proposals are unverified; symbolic verification is conditional on stored premises. Dashboard is read-only for adaptation. The registry and database are trusted local inputs; no tamper-proof policy authorization or production security claim. No background daemon, public deployment or paid API. V5 is owner-authorized, not independently certified. See [V5 acceptance](v5/ACCEPTANCE.md) and [full report](v6/INCREMENT.md).
