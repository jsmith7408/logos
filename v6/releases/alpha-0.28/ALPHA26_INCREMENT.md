Reflective appraisal combines bounded existing telemetry, active policy, descriptive confidence scores and recent improvement summaries. It is a single bounded appraisal, not arbitrary recursive self-modification.

An experiment compares both paths against operand-derived expected results plus fixed rejection cases. Rollback returns to exact-v1. Existing Strategy.run consults the persisted policy. No source-code writes or provider text execution. The experiment changes only whitespace handling, not intelligence or arithmetic algorithms; benchmarks deliberately exercise that known gap, not a blind held-out sample. The registry and SQLite are trusted local code/data; no tamper-proof policy authorization, external certification or production security claim.

Native symbolic inference is tried before optional exact-type loopback Ollama. Only the requested literal or its negation is admitted as a quarantined hypothesis; no fact/rule insertion or promotion. Live provider not exercised, mock tests only. General natural-language hypothesis extraction and independent truth verification remain incomplete.

Single-user local prototype; no background daemon, paid API or public deployment.
