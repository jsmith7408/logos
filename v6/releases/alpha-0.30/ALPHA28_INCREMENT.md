Explicit cycle generates questions, checks hypotheses, allocates 8–32 probability trials based on unresolved work, runs reproducible invariant-based experiments, and saves an appraisal. No background daemon or automatic strategy promotion. Alpha 0.27 fixed strategy regression gate remains available separately.
- Import operator-supplied external benchmark JSON, validate typed tasks, reject duplicates, hash dataset and score; source labels and independence unverified. Imported labels cannot activate strategies. Same-family generated tests do not constitute independent validation.
- In-house trainable bigram language component: bounded local corpus, counts stored in SQLite, deterministic next-token generation, no pretrained models or external inference. It does not establish truth or general language understanding. No independent general-purpose language model exists yet. Native generation and restart persistence tested.
- Public HTTPS evidence retrieval: explicit operator host allowlist, no query/credentials/redirects, public DNS addresses checked and selected address pinned with TLS hostname verification, GET only, text/plain or text/html, identity encoding, capped 64 KiB body, hashes and unverified snapshots. No automatic execution, parsing into accepted knowledge, or model call. DNS and response-header phases lack strict wall-clock guarantee; trusted operator chooses hosts. Live probe failed DNS; mocked retrieval, rejection of private addresses and redirects and quarantine tested. No live network success or security certification claimed.
