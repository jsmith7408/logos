# LOGOS V6 Alpha 0.29 — Native contextual language prototype

Baseline: Alpha 0.28, GitHub main 71a6aa7d408e6be100b5a7c6d321db124d8a7244. Verified all inherited SHA-256 manifest entries before development. Owner policy: no third-party AI inference, including externally or locally hosted pretrained AI models. No model weights, neural libraries, or external AI inference were used by the new application.

## Implemented
- Unicode case-folding tokenizer, capped vocabulary learned from explicitly approved text; unknown/begin/end tokens. A new training run rebuilds vocabulary and weights from the retained corpus rather than performing continual online learning.
- Native two-token ordered context neural language model: eight-dimensional trainable token embeddings, concatenated context, linear softmax output, cross-entropy and stochastic gradient descent through both output and embedding weights. Pure Python, seeded random initialization. Numerical finite-difference gradient test includes repeated context token. Distributional cosine similarity is observational, not verified semantic knowledge.
- Persistent corpus provenance, candidate checkpoints with SHA-256 integrity verification and finite-value shape validation. Explicit activation or rollback by checkpoint ID; no automatic strategy activation or source rewriting. Lower training loss is required to save a candidate, but is not a held-out regression gate. Maximum 32 corpus records, 1,500 aggregate training tokens, 128 vocabulary entries, 40 epochs, 16 checkpoints and 1.5 million row/epoch/vocabulary products. Single trusted local writer; hashes do not protect against an attacker who can change the database and checksums.
- Web learning requires explicit operator review of an exact excerpt from a stored snapshot with reproducible UTF-8 content and URL hash. Unreviewed web text cannot enter this training workflow. Approval is permission to learn text patterns, not authentication of factual claims. Generated text and embeddings never enter accepted facts or rules. No autonomous evidence promotion.
- Native command interface `learn`, `review-web`, `train-neural`, `activate-neural`, `generate`, `similar`, `chat`. Restricted conversation recognizes a supported-literal question and a calculation request; other requests abstain. Native symbolic inference remains conditional on stored premises. Previous bigram and native scenario interfaces remain available.
- Web retrieval now also requires membership in a fixed reviewed document-host list in `network29.py`, operator host allowlist and blocked API/inference path segments. Existing pinned public-address TLS GET, redirect refusal, byte cap and quarantine remain. Host allowlisting is not a guarantee about arbitrary site content, and not an OS egress sandbox; historical fixture interfaces remain in trusted Python code. No external model inference requests were made. Live public document probe failed DNS resolution again.
