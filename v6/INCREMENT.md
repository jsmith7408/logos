## Implementation
- `multidomain.py`: explicit arithmetic, isolated propositional scenarios and directed graph reachability. Native routes only. Default policies exact/global/abstain; opt-in cycle may select existing trimmed arithmetic, existing scoped inference, or new BFS. The logic evaluation contract specifically requires query-local relevance, not global consistency. Graph baseline abstains; its gains measure coverage.
- Bounded weakness ranking and candidate comparison, at most three domains per cycle. Separate generated dev/held-out sets (seeds 27112601 and 27112602), verified disjoint task fingerprints, 60 each per domain. Candidate selection uses development outcomes; held-out assessment is performed after selection. Activation requires positive gains, full accuracy and zero regressions in both splits, explicit `activate=True`, registry membership, and transactional policy update/history. Rollback per domain. Synthetic oracle: arithmetic operands/Fraction, logic construction labels, graph transitive closure. Same generator family and public seeds, not external or blind independent validation. Do not infer general intelligence improvements.
- Confidence scoring: one-bin Laplace-smoothed development correctness estimate; held-out Brier and absolute gap. No demonstrated general calibration or per-item uncertainty model. All labels and results unauthenticated.
- Dependency-aware explicit manual-source withdrawal: conservative downstream closure including polarities, budget failure before writes, preserve alternate sources and all rules, enqueue affected literal objectives for existing continuation worker. Attested sources require the existing verified lifecycle. No general automatic belief rewriting.
- Batch neuro-symbolic proposals: up to eight validated literals; native check first; one opt-in loopback model call only on unresolved literals. Strict allowlist JSON and quarantine; no model-supplied rules or fact promotion. Mocked tests only. Persistent policies, bounded history (100 records), proposal history and read-only self-model integrated into Strategy/dashboard. Existing routes unchanged; new `domain:` JSON route is explicitly scoped. No subjective consciousness claim.
