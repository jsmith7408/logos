## Implemented
- Four-token context, 12-dimensional trainable embeddings, scaled dot-product attention using the last context embedding as query, learned positional biases, 16-unit tanh hidden layer and softmax. Explicit backpropagation including repeated token and query contributions. Standard-library Python. Numerical finite-difference checks across seven parameter positions.
- Training-only vocabulary with up to 32 frequent whole-word pieces and character fallback; up to 128 entries including special tokens. Unknown targets are reported. Not full BPE or semantic extraction.
- Three explicitly approved document splits, provenance, normalized duplicate rejection, content fingerprints, training-only vocabulary, seeded bounded SGD, validation-based early stopping, separate test-loss check. Exact duplicate rejection does not prevent shared passages, template leakage or related distributions. Test data is reused for admission and is not an independent external holdout. Evaluation is mean token loss, not per-task correctness or fact verification.
- Candidate checkpoint with dataset, seed and prior-active binding; finite shape validation and content hash. Explicit activation recomputes all losses and requires train/validation improvement and test non-increase. Initial comparator is random initialization, not Alpha 0.29. Active subsequent training requires same dataset and vocabulary. Persistent activation and rollback history; rejected candidates cannot be activated through the new gate. Trusted single local writer/database; hashes are not protection from a malicious database editor. No arbitrary code rewriting.
- Native CLI learn-context, review-context-web, train-context, activate-context, rollback-context, generate-context. Explicitly approved exact web snapshot excerpts may enter training/validation/test. No automatic knowledge promotion. Restricted symbolic chat remains separate; neural generation is labeled unverified. Prior experimental paths are preserved and are not retroactively gated. No new live web test; previous DNS blocker remains unverified in this cycle.
